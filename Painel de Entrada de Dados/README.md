# 📊 Painel de Entrada de Dados em Excel com VBA

Bem-vindo ao repositório do meu **Painel de Entrada de Dados** desenvolvido em Microsoft Excel utilizando macros em **VBA (Visual Basic for Applications)**. Este projeto foi criado para automatizar, validar e agilizar o registro de informações de forma organizada e intuitiva.

---

## 🚀 Funcionalidades
- **Interface Amigável:** Formulários (UserForms) personalizados para inserção de dados sem precisar mexer diretamente nas planilhas.
- **Validação de Dados:** Impede o envio de campos obrigatórios vazios ou com formatos incorretos.
- **Automação de Registros:** Os dados preenchidos no painel são salvos automaticamente na base de dados (tabela) correspondente.
- **Limpeza Rápida:** Botões para limpar o formulário com um único clique após o cadastro.

---

## 🛠️ Tecnologias Utilizadas
- **Microsoft Excel** (versão recomendada: Excel 2016 ou superior / Microsoft 365)
- **VBA (Visual Basic for Applications)**

---

## ⚙️ Como Utilizar

1. **Baixe o arquivo:** Faça o download do arquivo principal do Excel contendo as macros (geralmente com a extensão `.xlsm`).
2. **Habilite as Macros:** 
   * Ao abrir o arquivo no Excel, clique no botão **"Habilitar Conteúdo"** ou **"Habilitar Macros"** na faixa de aviso amarela no topo da tela (o VBA precisa disso para rodar os formulários).
3. **Utilize o Painel:**
   * Preencha os campos solicitados no formulário e clique em **OK**.
   * Navegue até a tabela chamada BASE através da guia ou do ícone no próprio painel e confira o item inserido.
